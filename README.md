# Daniela Valdez — Portfolio

UX/UI designer and web professional. This is my portfolio site, built as a single page that looks like a desktop: open the folders to see each project.

- **UX/UI & Web:** Entravision.com, Noticias & El Botón, NBC Palm Springs App, Community App
- **Branding & Marketing:** BanCoppel, Coppel Pay, Reyna 103.1 FM, Createch Energías, brand identities
- English and Spanish (EN / ES toggle in the top bar)

## Run it

Open `index.html` in a browser, or publish it with GitHub Pages (Settings → Pages → Deploy from branch → `main`, folder `/`).
